        version 0.1.0                   8 oct 2026

+ first build: editor and window shell, no emulator core yet
+ project = .zip with sketch (.ino, .h, .c, .cpp); Load (button, Ctrl+O,
  drag & drop); main .ino (with setup() / loop()) is first tab, other
  sources follow alphabetically, then text files (.txt)
+ loose .ino / .h files are added to open project (or start new one)
+ changed file is marked with * before its name on its tab; project name
  in toolbar gets dot while anything is unsaved
+ Save (button, Ctrl+S): whole project back as <name>.zip — unchanged
  files byte for byte, changed ones in their own encoding (UTF-8, UTF-8 BOM
  or Windows-1251) and line endings (CRLF / LF); other files of archive
  are kept untouched
+ editor (CodeMirror 6): C / C++ highlighting, own undo history per tab,
  find / replace, go to line, folding, bracket matching, multi-cursor,
  comment toggle, auto-closed brackets
+ color themes as in Visual Studio Code: Dark+, Light+, Monokai,
  Solarized Dark / Light, High Contrast Dark / Light, Auto (system);
  toolbar button switches light / dark
+ Options window (Board / Editor / About): Arduino Nano (ATmega328P) or
  Arduino Mega 2560 (ATmega2560); font, font size, tab size, line numbers,
  word wrap, current line, whitespace, auto-close brackets, keep session
+ session (open project, unsaved changes, active tab) is kept in browser
  and restored on next visit
+ LED window: 16x16, 24x12, 32x32, 64x64 (and sketch's own size), square
  pixels sized by window, grid on / off; drag by title, resize by edges;
  wiring as in GyverMatrix: zigzag / parallel, start corner, direction
+ LED "From sketch": WIDTH / HEIGHT / MATRIX_TYPE / CONNECTION_ANGLE /
  STRIP_DIRECTION (and kMatrixWidth / kMatrixHeight / kMatrixSerpentineLayout
  of FastLED examples) read from sources, also on project load
+ LED window: mouse over pixel shows x, y, leds[index] and its color
+ Start / Stop (F5): until emulator core is built, test pattern runs along
  strip in wiring order (white head from leds[0])
+ status bar: board, run state, line / column, indentation, encoding,
  line endings, language
+ Help window (F1), keys: Ctrl+O, Ctrl+S, F5, F6, Ctrl+, , Alt+1..9


        version 0.2.0                   8 oct 2026

+ sketch really runs: Start (F5) compiles project with clang 21 (LLVM,
  YoWASP build for WebAssembly) right in browser and runs it as WebAssembly
  in real time; test pattern of 0.1.0 is gone
+ compiler is downloaded once (about 26 MB, rt/*.gz, unpacked by page),
  then comes from browser cache; it starts loading in background when
  project is opened
+ Arduino core for Nano / Mega 2560: pins and A0.., millis / micros /
  delay / delayMicroseconds, digital / analog I/O, random / map / constrain
  and other macros, String, Print / Stream, Serial (Serial1-3 on Mega),
  EEPROM (1 KB / 4 KB), PROGMEM / pgm_read_* / F() / far pointers,
  avr/pgmspace.h, avr/io.h, avr/interrupt.h, avr/eeprom.h, util/delay.h
+ FastLED 3.7.8 built in (stub platform): FastLED.show() hands final pixels
  (brightness, color correction, power limit, dithering, color order) to
  LED window and takes its real time on wire (30 us per WS2812 LED)
+ .ino files are joined as in Arduino IDE (main one first, then
  alphabetically) with function prototypes; .h / .c / .cpp of sketch
  folder (and src/) are compiled too; #line keeps file names and lines
+ -fpermissive as in Arduino IDE: conversions that g++ only warns about
  (const discarded, pointer <-> integer) get cast, file is compiled again
  and Problems shows warning (effects.ino:1122 of GyverMatrix)
+ names AVR libc lacks but sketches use as variables (y1, j0, index ...)
  do not clash with C library
+ Verify (F7, Ctrl+R): compile only; build is cached while sources, board
  and optimization stay same
+ panel below editor (Ctrl+J), as in VS Code: Problems (click = go to
  line), Output (compiler log), Serial Monitor (output, input line with
  line ending, autoscroll, baud rate of Serial.begin)
+ errors and warnings are underlined in editor, with marker in gutter;
  error / warning counts in status bar
+ LED window: buttons for input pins of running sketch (INPUT /
  INPUT_PULLUP): hold = pressed, Shift+click = keep pressed (D3 of
  GyverMatrix switches modes)
+ LED window: "LED-like" display (linear light of LED converted to sRGB of
  monitor) or raw values
+ Options / Board / Build: optimization -O0 (fast build, default), -O1,
  -O2, -Os
+ status bar: compiling / loading compiler, loops and FastLED.show() per
  second while running
+ .htaccess / web.config: cross-origin isolation headers (sketch waits in
  delay() without loading CPU), .gz served as is
@ LED window: frame has length of strip (NUM_LEDS + 1 of GyverMatrix is
  fine); size still comes from sketch


        version 0.3.0                   8 oct 2026

@ LED window: all controls are in its title bar: size box, rebuild with
  this size, size from sketch, pause, speed, scale, fit, effects, inputs,
  reset and close
+ size box understands 24x12, 24-12, 24 12, 24*12, 24х12, 2412 (and 16 =
  16x16)
+ rebuild with size: sketch is compiled with WIDTH / HEIGHT (or
  MATRIX_WIDTH, kMatrixWidth ...) of box instead of its own — only for
  this build, code is not changed — and restarted; "from sketch" goes back
  to sketch's size
+ pause / continue (also Space outside editor): sketch clock stands still
+ speed 0.1x .. 10x: sketch clock (millis, micros, delay, time of
  FastLED.show() on wire) runs faster or slower than real time
+ scale 0.1x .. 5x (1x = 16 px per LED) fits window to matrix; "fit"
  does it on request
+ reset: same build starts again from setup()
+ Inputs window: each pin sketch uses — mode, level, PWM, tone, FastLED
  data pin with its LED count; button for INPUT / INPUT_PULLUP pins (hold,
  Shift+click keeps it), slider or noise for analogRead pins
+ tabs can be dragged to another place; order is kept in session
@ closing LED window stops sketch
@ wiring (zigzag / parallel, start corner, direction) and colors
  (LED-like / raw) moved to Options -> LED

        version 0.8.0                   9 oct 2026

+ .c sketches (Soulmate style, project without .ino): .c files are

  own), wiring zigzag from bottom left, right (as XY() of pattern)
! C++ library headers are not used for sketches (-nostdinc++), as on AVR:
  <math.h> is C header, so float sqrt(float) of sketch does not clash with
  libc++ overloads (AttractingBoids.c)
* -fpermissive casts of last build are applied before next build of same
  project: rebuild with new size needs one compile round, not two
  (GyverMatrix: about half time)
+ Output: "Caught up to m:ss in x s" after rebuild with continuation
* .htaccess / web.config: type of .c files
